3、当我使用GPU跑数据的时候，比如说跑deepseekr17b，如何知道GPU资源是否真正被用上了？

如下图所示，虽然利用率为0，但是专用GPU内存不等于0，表示使用上了。

​
Torch -> cuda Tool Kit -> 显卡驱动 -> 显卡芯片
安装pytorch时cuda tool kit也装进去了，但是那只是给python环境用的库，
电脑上其他应用想要使用显卡(比如说ollama部署运行大模型），得有对应的cuda库调用，ollama应该是集成了cuda tool kit，因此上图所示利用上gpu了。

但如果想要使用一些本身没有集成cuda tool kit库的三方工具，需要安装电脑系统级别的cuda tool kit

nvidia-smi 命令查看输出右上角的 CUDA Version项。例如，若显示 12.5，则表示你当前的显卡驱动最高支持CUDA 12.5。你安装的CUDA Toolkit版本不应高于此版本，访问NVIDIA CUDA Toolkit Archive 下载对应版本的即可（选用local）

直接双击安装即可，使用推荐的安装，一路next，默认安装路径：C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.0 当然，也可以改成自定义安装。检查（配置环境变量）

查看是否安装成功

nvcc --version


同时上面验证pytorch的gpu版本也能正常打印信息，不冲突。
ollama运行deepseekr17b的时候使用独立显卡，见：“大模型部署”下的“ollama”
